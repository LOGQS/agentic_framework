Logic Flows

Build conditional loops and multi-step agent execution

Overview

Logic flows enable agents to execute multiple steps based on conditions. Instead of single-shot execution, agents can loop, make decisions, and execute complex workflows.

LogicRunner Class

The core abstraction for conditional agent loops:

from agentic import LogicRunner, LogicConfig, LogicCondition

config = LogicConfig(
    logic_id="my_loop",
    max_iterations=10,
    stop_conditions=[...]  # List of LogicCondition objects
)

runner = LogicRunner(agent_runner, context, patterns, config)

# Execute until stop condition
async for event in runner.run_stream(initial_input):
    if event.type == "step_complete":
        print(f"Step {event.result.iteration} done")

Stop Conditions

Define when the logic flow should terminate using LogicCondition:

Pattern-Based Conditions

Stop when a specific pattern is detected in the response:

from agentic import LogicCondition

# Stop when "DONE" appears in response
stop_on_done = LogicCondition(
    pattern_set="default",
    pattern_name="response",
    match_type="contains",
    target="response"
)

Context-Based Conditions

Stop based on context values:

# Stop when context key matches value
stop_when_complete = LogicCondition(
    pattern_set="default",
    pattern_name="response",
    match_type="equals",
    target="context:task_complete"
)

Regex Conditions

Stop when regex pattern matches:

# Stop when confidence score > 95% appears in response
stop_on_high_confidence = LogicCondition(
    pattern_set="default",
    pattern_name="response",
    match_type="regex",
    target="response"
)

Helper Functions

Use helper functions for common loop patterns:

Loop N Times

from agentic import loop_n_times

runner = loop_n_times(agent_runner, context, patterns, n=5)

async for event in runner.run_stream("Execute 5 iterations"):
    if event.type == "step_complete":
        result = event.result
        print(f"Iteration {result.iteration}: {result.status}")

Loop Until Pattern

from agentic import loop_until_pattern

runner = loop_until_pattern(
    agent_runner,
    context,
    patterns,
    pattern_set="default",
    pattern_name="response",
    target="response",
    max_iterations=20
)

async for event in runner.run_stream("Complete this multi-step task"):
    if event.type == "step_complete":
        print(f"Step {event.result.iteration} done")

Loop Until Regex

from agentic import loop_until_regex

runner = loop_until_regex(
    agent_runner,
    context,
    patterns,
    regex_pattern=r"confidence.*?(\d+)%",
    target="response",
    max_iterations=10
)

async for event in runner.run_stream("Refine until confident"):
    pass

Verification Loop

Keep trying until verification succeeds:

flow = LogicFlow(
    runner=runner,
    max_iterations=5,
    stop_conditions=[
        ToolResultStopCondition(
            tool_name="verify",
            condition=lambda r: r.success and r.output.get("valid") == True
        )
    ]
)

async for event in flow.run("Generate and verify solution"):
    pass  # Loops until verification passes

Incremental Refinement

Refine output until quality threshold met:

class QualityStopCondition(StopCondition):
    def check(self, result, context):
        quality = context.get_str("quality_score")
        return quality and float(quality) >= 0.9

flow = LogicFlow(
    runner=runner,
    max_iterations=10,
    stop_conditions=[QualityStopCondition()],
    loop_input_fn=lambda prev_result: "Improve the previous output"
)

Loop Input Functions

Customize input for each iteration:

def build_loop_input(previous_result: AgentStepResult) -> str:
    # Use previous output to guide next step
    if previous_result.status == AgentStatus.TOOL_EXECUTED:
        return "Analyze the tool results and continue"
    else:
        return "Continue with next step"

flow = LogicFlow(
    runner=runner,
    max_iterations=15,
    stop_conditions=[StatusStopCondition(AgentStatus.DONE)],
    loop_input_fn=build_loop_input
)

Error Handling

Handle errors gracefully in logic flows:

flow = LogicFlow(
    runner=runner,
    max_iterations=10,
    stop_conditions=[
        StatusStopCondition(AgentStatus.DONE),
        StatusStopCondition(AgentStatus.ERROR)  # Stop on error
    ]
)

final_result = None
async for event in flow.run(user_input):
    if event.type == "step_complete":
        final_result = event.result

if final_result.status == AgentStatus.ERROR:
    print(f"Flow failed: {final_result.error_message}")
else:
    print(f"Flow completed: {final_result.segments.response}")

Iteration Limits

Always set max_iterations to prevent infinite loops:

flow = LogicFlow(
    runner=runner,
    max_iterations=100,  # Safety limit
    stop_conditions=[...]
)

# Flow will stop at max_iterations even if conditions not met
Best Practice: Always include an error status stop condition to handle failures gracefully.

Context Monitoring

Monitor context health during execution:

class ContextHealthCondition(StopCondition):
    def check(self, result, context):
        # Check if context is getting too large
        keys = context.list_keys()
        if len(keys) > 1000:
            return True  # Stop if too many keys

        # Check for specific markers
        shutdown_signal = context.get_str("shutdown")
        if shutdown_signal == "true":
            return True

        return False

Multi-Condition Logic

Combine multiple stop conditions with OR logic:

flow = LogicFlow(
    runner=runner,
    max_iterations=50,
    stop_conditions=[
        StatusStopCondition(AgentStatus.DONE),
        StatusStopCondition(AgentStatus.ERROR),
        ToolResultStopCondition("verify", lambda r: r.success),
        ContextStopCondition("abort", lambda v: v == b"true")
    ]
)

# Stops when ANY condition is met

Real-World Example

Research agent that iterates until comprehensive answer found:

class ComprehensiveAnswerCondition(StopCondition):
    def check(self, result, context):
        response = result.segments.response
        if not response:
            return False

        # Check if response is comprehensive (simple heuristic)
        if len(response) < 200:
            return False

        # Check if sources were cited
        if "source" not in response.lower():
            return False

        return True

def research_loop_input(prev_result):
    if prev_result is None:
        return None  # Use initial input

    # Ask agent to expand on previous findings
    return "Expand on previous findings with more detail and sources"

research_flow = LogicFlow(
    runner=research_agent_runner,
    max_iterations=5,
    stop_conditions=[
        ComprehensiveAnswerCondition(),
        StatusStopCondition(AgentStatus.ERROR)
    ],
    loop_input_fn=research_loop_input
)

async for event in research_flow.run("Research quantum computing applications"):
    if event.type == "step_complete":
        print(f"Research iteration {event.result.iteration} complete")

Best Practices

  • Always set reasonable max_iterations limits
  • Include error status in stop conditions
  • Use context to communicate between iterations
  • Provide clear loop input to guide agent progress
  • Monitor iteration count and context size
  • Test stop conditions thoroughly to avoid infinite loops
  • Log iteration results for debugging
